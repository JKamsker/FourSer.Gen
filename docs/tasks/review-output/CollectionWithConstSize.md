## Performance opportunities
- No collection-level bulk fast path is obviously missing here: each `Entity` has a variable-size `string`, so the fixed-size collection itself cannot be emitted as one contiguous primitive block.
- Stream serialization still performs many small writes. `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:130` calls `Entity.Serialize` once per item, and each entity then writes `Id` separately from the string payload in `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:230` and `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:244`. Fusing `Id` with the already-buffered string length/payload, or batching multiple entities into one rented buffer, would reduce stream writes.
- Stream deserialization also performs small reads per entity. The fixed-size collection loop in `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:77` delegates to `Entity.Deserialize`, which reads `Id` and the string separately in `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:203` and `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:204`. Reading the fixed-width prefix (`Id` + string length) together before pulling the UTF-8 payload would cut stream IO calls.
- Minor codegen cleanup: `checked((int)10)` is emitted repeatedly for a literal in `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:59`, `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:60`, `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:77`, and `tests/FourSer.Tests/GeneratorTestCases/CollectionWithConstSize/CollectionWithConstSize.RunGeneratorTest.verified.txt:78`. The runtime impact is negligible, but it is redundant generated output.
