## Performance opportunities
- `tests/FourSer.Tests/GeneratorTestCases/CollectionByteCount/CollectionByteCount.RunGeneratorTest.verified.txt:130-137` writes the collection count and then serializes each `Cat` separately to the stream. For larger lists, batching one `Cat` per contiguous buffer, or batching several cats into a rented buffer, would reduce stream writes.
- `tests/FourSer.Tests/GeneratorTestCases/CollectionByteCount/CollectionByteCount.RunGeneratorTest.verified.txt:232-246` writes `Id` and `Name` in separate stream operations. If the generator fused `Id` with the already-buffered string payload, each `Cat` could usually be emitted with one stream write instead of two.
- `tests/FourSer.Tests/GeneratorTestCases/CollectionByteCount/CollectionByteCount.RunGeneratorTest.verified.txt:78-82` and `:205-206` still deserialize through small per-field stream reads. There is room to fuse each item's fixed-width prefix (`Id` plus string length) into fewer reads before consuming the UTF-8 payload.
