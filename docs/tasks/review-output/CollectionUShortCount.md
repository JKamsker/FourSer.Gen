- `UShortCountTest.Deserialize(...)` currently fills the pre-sized list via repeated `Add(...)` in `tests/FourSer.Tests/GeneratorTestCases/CollectionUShortCount/CollectionUShortCount.RunGeneratorTest.verified.txt:60-64` and `:79-83`. - Stream serialization still performs one collection-count write plus one nested `Cat.Serialize(stream)` call per item in `tests/FourSer.Tests/GeneratorTestCases/CollectionUShortCount/CollectionUShortCount.RunGeneratorTest.verified.txt:130-137`. Inside each item, `Id` is written separately before the fused string payload in `tests/FourSer.Tests/GeneratorTestCases/CollectionUShortCount/CollectionUShortCount.RunGeneratorTest.verified.txt:232-246`. A single per-item buffer for `Id + NameLength + NameBytes`, or a small reused collection buffer, would reduce stream writes for large collections.

If stream throughput matters for large `Cats` collections, buffering the fixed-width prefix before decoding the UTF-8 payload would cut `ReadExactly` calls.
